# LABORAT-RIO-DE-PLANEAMENTO-E-DESENVOLVIMENTO-DE-SOFTWARE

📊 LPDS Evaluation Management System
Software Planning and Development Laboratory | UTAD 2024/2025

This repository contains the final project developed for the Laboratório de Planeamento e Desenvolvimento de Software (LPDS) course. The goal was to build a robust Windows-native application to help professors manage student evaluations, group work, and academic performance analysis.

📑 Project Context
Development Journey: This project was built incrementally throughout the entire semester, following a rigorous software engineering lifecycle from requirements to final implementation.

Repository Origin: The project was originally derived from a private template provided by the faculty. This repository reflects the complete evolution of the software, showcasing continuous integration through multiple commits and iterative updates to meet all academic milestones.

🚀 Key Features
User & Profile Management: Customization of the professor's profile including name, email, and photo.

Student Administration: Full CRUD operations for student lists with the ability to import data from CSV/XLSX files.

Task & Group Management: Creation and weighting of evaluation tasks associated with student groups.

Grading & Analytics: * Matrix-style grade sheets (pautas) showing final evaluations.

Real-time statistical analysis with histogram visualization of grade distribution.

Persistence: Secure data storage using XML format in the user's local directory.

🛠️ Technical Stack
Language: C#.

Framework: .NET 9.0 & WPF (Windows Presentation Foundation).

Architecture: Model-View-ViewModel (MVVM) pattern to ensure clean separation of concerns.

Design: Specification followed UML Use Case and Class diagrams.
